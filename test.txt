+ ពាក្យបញ្ជា (Git Commands) សំខាន់ៗដែលត្រូវចេះ៖
git init : ចាប់ផ្តើមប្រើប្រាស់ Git ក្នុង Project របស់អ្នក។
git status : មើលស្ថានភាពនៃឯកសារដែលបានកែប្រែ។
git add . : បន្ថែមឯកសារចូលទៅក្នុង Staging Area។
git commit -m "សាររៀបរាប់" : រក្សាទុកកំណែប្រែ (Commit) ជាមួយសារបញ្ជាក់។
git push : បញ្ជូនកូដពីកុំព្យូទ័ររបស់អ្នកទៅកាន់ GitHub។
git pull : ទាញយកកូដចុងក្រោយពី GitHub មកកុំព្យូទ័រវិញ។
