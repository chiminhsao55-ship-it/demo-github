1. តើ Git ជាអ្វី?
Git — Version Control System
Git ជា Tool ដែលប្រើសម្រាប់តាមដានការផ្លាស់ប្តូរកូដនៅលើកុំព្យូទ័ររបស់អ្នក។
- រក្សាទុកប្រវត្តិនៃការកែប្រែកូដ។
- អាចត្រឡប់ទៅកូដចាស់បាន។
- អាចបង្កើត Branch សម្រាប់សាកល្បងមុខងារថ្មី។
- អាចគ្រប់គ្រង Project ដោយមិនចាំបាច់ភ្ជាប់ Internet។
